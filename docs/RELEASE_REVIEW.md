## 1.0.6 发布复核

- 实际复现并修复关闭标签页时异步写入恢复会话数据、页面全部失联后保持运行与静音的问题。
- 为修复增加 9 项生命周期测试，并增加 2 项 HTTP UUID 兼容测试；连同原 16 项共 27 项。
- 权限、匹配域名和无运行依赖的设计不变；诊断导出保持显式字段白名单。
- 本地源码检查、回归测试、安装包独立 CRC 和逐文件内容核验通过。没有真实账号或课程验收，作为预发布版本提供。
- 页面 MAIN 世界的事件可被同页脚本观察或伪造、HTTP 页面无法保证传输安全等边界仍然存在；不宣称独立安全审计或绝对无漏洞。
