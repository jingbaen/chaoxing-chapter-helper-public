# 学习通章节助手

面向 Microsoft Edge / Google Chrome 120 及以上版本的 Manifest V3 扩展。
顺序控制章节视频与文档，观察页面任务完成标记后再切换。当前版本 **1.0.6**，作为预发布版本提供，真实课程兼容性仍待验收。
运行时没有第三方依赖、远程脚本、题库、AI 服务或统计上传。

## 功能

- 视频速度可选 1、1.25、1.5、2 倍，默认 2 倍；默认静音当前课程标签页。
- 多个视频和 PPT 按页面顺序处理，每次只操作一个精确绑定的任务。
- 滚动文档阅读器、等待平台任务标记，确认后自动下一节。
- 可选择鼠标离开后继续播放；后台巡检每 30 秒执行一次，浏览器可能延迟调度。
- 碰到题目、验证码、人脸验证、登录失效、播放器错误或任务确认超时则暂停。
- 支持暂停及导出经过字段白名单处理的诊断记录。
- 关闭标签页时阻止迟到的后台写入恢复会话；导航结束后无法连接受支持页面，或巡检发现全部页面失联时，清理会话并恢复助手修改的标签页静音。

## 安装

1. 下载仓库源码或发布 ZIP，解压并将文件夹放在固定位置。
2. Edge 打开 `edge://extensions/`；Chrome 打开 `chrome://extensions/`。
3. 开启开发者模式，选择“加载解压缩的扩展”，选择直接包含 `manifest.json` 的文件夹。
4. 刷新已经打开的课程页面，进入具体子单元，点击浮动面板或工具栏弹窗的“开始”。

不需要脚本管理器、账号密码或 API 密钥。安装后保留文件夹位置。
更新时替换安装目录中的文件，在扩展管理页重新加载，再刷新课程页。

## 使用与限制

默认开启文档处理、离开继续播放、自动下一节和静音。调整选项前先暂停。
收起浮动面板不会暂停；“暂停”会停止自动操作并尝试恢复助手修改的播放设置及标签页静音。
从当前打开位置向后处理，不补学此前章节；会话完成计数不能代替课程总进度。

播放结束或阅读器触底后最多等待 20 秒确认；平台没有确认就暂停。
如果自动播放被阻止，手动点击原播放器后再开始；倍速不被接受时改为 1 倍。
页面冻结、关闭浏览器和电脑休眠期间不能播放。平台改版可能导致识别失效。
任务完成以平台显示及刷新后的记录为准，不承诺课程学分或完整课程完成。

此项目与平台无隶属关系。请在有权访问的课程中使用并遵守课程要求；需要本人处理的题目和身份验证由本人完成。

> 本项目仅供学习与个人研究使用。自动化播放、滚动和切换可能违反课程平台服务条款或学校规定，可能导致账号被限制、学习记录无效或成绩受影响；使用风险由使用者自行承担。作者不保证完成课程、学分或成绩，也不对平台判定负责。

## 隐私与权限

仅申请 `storage`、`alarms`。脚本匹配超星及相关阅读器的三个域名范围，详见 [PRIVACY.md](PRIVACY.md)。
不包含账号、Cookie 或密钥，不直接读取密码或 Cookie，也不直接请求课程接口。
课程页面原有播放器/阅读器仍可能按平台机制提交学习记录。
导出文件不含任务标题、课程编号、任务编号、URL、运行日志或精确操作时间。

## 开发

安装 Node.js 22 或以上版本即可，无需 `npm install`。

```sh
npm run verify
npm run package
```

`verify` 运行语法、配置、敏感内容规则检查及回归测试。
`package` 仅按白名单将安装文件和许可证打包到 `dist/`，只需 Node.js，无需外部压缩工具。
检查脚本是辅助规则，不能证明不存在任何敏感信息。

| 文件 | 用途 |
| --- | --- |
| manifest.json | 扩展权限、入口与页面匹配范围 |
| background.js | 后台调度、会话存储与巡检 |
| engine.js | 无 DOM 的任务状态机 |
| page-agent.js | 页面播放器、阅读器和任务标记适配 |
| bridge.js | 扩展桥接及浮动面板 |
| popup.* / diagnostics.js | 弹窗及白名单诊断导出 |
| scripts/ / tests/ | 发布检查、打包与可重复测试 |
